privacidad

Esta web no guarda datos personales: el formulario no envía nada y la analítica no usa cookies.

Responsable

Daniel Castaños Mefle, titular de este sitio de demostración. Sus datos de contacto están en el aviso legal de danimefle.com.

El formulario de contacto

El formulario de la página de contacto es de demostración. Sus campos no tienen nombre de envío y el botón solo se activa cuando el JavaScript de la página ha instalado el código que lo intercepta: lo que escribas se comprueba en tu propio navegador y, al pulsar «Enviar», se borra. Sin JavaScript el botón queda desactivado. En ningún caso se manda nada a un servidor, no se guarda y nadie lo lee.

Analítica

Para saber cuántas visitas tiene la web usamos Plausible, servido desde analytics.danimefle.com. Plausible no usa cookies ni guarda tu dirección IP. Para contar visitantes únicos usa la IP y el navegador durante la visita para calcular un identificador anónimo que cambia cada día y no se guarda; con eso solo se ven cifras agregadas (páginas vistas, país, tipo de dispositivo y página de procedencia). Como analytics.danimefle.com es una instalación propia, el responsable de ese recuento es el titular del sitio.

Tus derechos

Como no guardamos datos personales tuyos, no hay datos guardados que consultar, corregir o borrar. Si tienes cualquier duda sobre esta web, puedes escribir al titular a través de danimefle.com.
